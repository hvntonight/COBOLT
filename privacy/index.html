隐私声明

Cobolt 是一款 local-first 的 macOS 文件保险箱。本声明说明当前 Cobolt macOS 版本、官网与支持页面如何处理信息。

一页摘要

我们设计 Cobolt 的核心工作流为本地优先：你的文件、保险箱目录和解锁过程在你的 Mac 上完成。Cobolt 不要求账号，不把核心文件同步到 Cobolt 云端，也不为核心任务运行遥测或广告追踪。

◎

一句话：你把文件交给 Cobolt，是为了让它们留在你的设备上，而不是交给我们保管。

1. Cobolt App 中的信息

你主动放入保险箱的内容

你选择导入的文件、保险箱名称、文件名、大小、类型、时间等目录元数据，以及保险箱的本地设置，会保存在你的 Mac 上。Cobolt 使用本地 authenticated encryption 保存保险箱内容；核心文件不会上传到 Cobolt 的服务器。

用于解锁和安全控制的信息

密码用于派生保险箱密钥；Touch ID 由 macOS 的安全机制处理；recovery key 用于在你启用后恢复访问。密码、master key 与解密后的文件字节不会通过 web bridge 离开原生 macOS 应用。

临时解密副本

打开 Quick Look 或其他需要解密内容的系统流程时，系统可能需要一个临时明文副本。Cobolt 在锁定或退出时会尽力移除这些副本，但 SSD 上的删除不等同于取证级安全抹除。请在共享设备上使用时，同时遵循 macOS 的账户和磁盘安全设置。

诊断、广告和账号

当前核心工作流不要求创建 Cobolt 账号，不运行 Cobolt 广告追踪，也不把核心操作发送给 Cobolt 遥测服务。如果未来版本新增分析、崩溃报告、云同步或其他数据处理，我们会在功能发布前更新本声明，并在适用时提供选择。

2. 购买与 Apple

Cobolt Pro 使用 Apple StoreKit 处理购买和恢复购买。付款卡信息由 Apple 处理，Cobolt 不接收你的完整支付信息。App 只需要读取 Apple 返回的商品或 entitlement 状态，以决定是否启用 Pro 功能。

Apple 可能按照其自身隐私政策处理 App Store、StoreKit 和设备相关信息。请参阅 Apple 隐私政策 与 Apple 媒体服务条款。

3. 官网与第三方

本官网是一个静态 GitHub Pages 站点。Cobolt 自己不设置广告 cookie、不要求登录，也不在此页面运行产品分析。GitHub 仍可能按照其服务条款和隐私声明处理标准的访问日志、网络安全信息与托管所需数据。请参阅 GitHub 隐私声明。

页面中的 Apple、GitHub 或其他链接会把你带到第三方网站；第三方网站的处理方式由其各自的隐私声明负责。

4. 保存、导出与删除

保险箱和文件会保留在你的 Mac 上，直到你在 Cobolt 或 Finder 中删除它们，或删除应用数据。Cobolt 没有一个替你保管这些文件的在线账号，因此不存在向 Cobolt 服务器申请“删除账户文件”的流程。

如果你删除保险箱，请先确认已备份仍需要的内容。密码遗失且没有 recovery key 时，设计上无法恢复保险箱内容；这是一项安全边界，而不是 Cobolt 可以绕过的支持流程。

5. 联系我们

如果你对隐私或数据处理有问题，请通过 Cobolt GitHub Issues 联系维护者。请不要在公开 issue 中上传密码、recovery key、真实身份证件或其他敏感文件。

我们会在产品功能或数据实践发生实质变化时更新本页面，并在页面顶部更新生效日期。
